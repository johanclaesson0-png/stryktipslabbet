# V24 – expertbarometer
50 kandidater, inte 50 bevisat oberoende experter. Registret anger källgrupp och typ (namn/pseudonym, redaktion, prognossajt). Regional etikett avser primär källa, inte medborgarskap.

## Pilot
4980: efterhandsgranskning av daterade svenska artiklar och Forecast Records individuella 90-minutersval. Källans registreringstid måste vara före Stryktipsets gemensamma spelstopp, inte bara matchstart. TT:s arkivsida saknar oberoende tidstämpel; markeras postclose_page. Ingen retrospektiv observation räknas som faktiskt fryst. Endast uttryckliga tecken, inte oddsmarknader som DNB, handicap eller kombinerade spel. Artikelförstaval är ofta streckvärdesval, inte ren sannolikhetsprognos. Systemförslag redovisas separat, en delad röst för garderingar. Victor och Poolarn är samma publicistgrupp; namn räknas också separat, men gruppmåttet reducerar övervikt. Syndikering mellan olika grupper kan kvarstå. Ingen modelljustering.

## Insamling
Hämta aktuell data/latest.json och data/analysis/<draw>.json. Använd panel.json som sökregister. Sök för aktuellt datum och exakta matchpar på publicistens webbplats; för Forecast Record, öppna matchens 1X2-lista, kontrollera exakt registreringstid och originalkälla. Svenska systemartiklar: välj senaste daterade versionen och explicit stora systemet, eller tydligt rubricerade förstaval. Hämta bara tillåtet, offentligt material; spara fakta (tecken, lagnamn, avläsnings- och källtider och länk), inte hela artiklar. Varken paywall eller teknisk spärr kringgås. 
Spara/uppdatera data/v24_inputs/<draw>.json före cutoff med samma schema som 4981. Faktisk avläsningstid i UTC, aldrig bakdatering. Datum utan klockslag: använd dagens slut som konservativ övre gräns, eller markera saknad tills tid kan styrkas. Upprepade versioner av samma expert, match och tipstyp: senaste avläsning, motstridiga lika nya val utelämnas. Endast 90 minuter. Fält evidence: article_timestamp, article_date_upper_bound, archive_recorded, direct_preclose (tid för faktiskt observerad aktuell sida). 
Kör på fredag och lördag före stopp; workflow aggregerar på push och ordinarie schema. Inga nya förhandsrapporter efter cutoff. Publiceringen använder sparad rapport; GitHub Actions kan vara fördröjd, därför behövs tidig sista insamling. 
Ingen automatiserad scraping utan verifierade rättigheter. Kandidatlistan är inte en automatisk datakälla; mänsklig/källgranskad insamling krävs. En schemalagd researchkörning kan göra detta om web- och GitHub-åtkomst är tillgängliga. Historisk utvärdering: individuella träffar, delad systemträff och oddsens bästa tecken på samma match; kräver flera omgångar och kalibrering innan expertdata påverkar prognosen.
